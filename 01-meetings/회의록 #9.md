## IV. 회의 내용

### 1. 개발 진행 경과

이은성은 SubSlash(구독 디톡스 앱)의 프로토타입을 Vercel에 배포하고 GitHub에 공개하였다. 이온은 이를 기반으로 E2E 테스트를 진행하며 UI/UX 및 데이터 흐름 관련 다수의 개선사항을 전달하였고, 이은성이 이를 순차적으로 반영하였다.

### 2. 기술 스택 및 인증 결정

로그인/회원가입 기능을 구현하는 과정에서, 이메일 인증은 GitHub Student Pack으로 확보한 고정 도메인을 기반으로 적용하기로 하였다. 이메일 영수증 자동 파싱 기능은 구글 API의 사전 심사가 필요하여, 스코프를 최소화해 심사를 신청하고 우선은 수동 입력 기반으로 개발을 진행하기로 하였다. 데이터베이스는 Turso를 사용하기로 결정하였으며, 교수님 보고를 위해 GitHub organization 레포로 이관하여 기준 레포로 활용하기로 하였다.

### 3. 기능 보완 및 배포

개인정보처리방침 추가, 구독 서비스별 요금제 구분, 절약 현황 화면 개선 등 UI 정비를 진행하였고, www.subslash.me 고정 도메인 연결을 완료하였다. 계정 연동, 공유 링크, 샘플/실사용 데이터 혼합 등 주요 버그를 수정하였다.

### 4. 주제 방향 및 향후 요청

09월 16일 기준 팀 내에서 다른 후보 아이디어(LMS 공지 기반 알림 서비스 등)도 공유되었으나, 현재는 SubSlash를 1순위로 두고 계획서를 업데이트하기로 하였다(최종 확정은 아님). 같은 날 교수님으로부터 주제 변경사항에 대한 업데이트 요청을 받아, 진행상황 보고를 준비 중이다.
