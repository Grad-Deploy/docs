## IV. 회의 내용

### 1. Task별 작업 완료 현황 점검

회의록 #6에서 배분된 4개 Task의 작업이 모두 완료되었음을 각 담당자가 보고하였다. Task 1(이은성), Task 2(이혁제), Task 3(이온), Task 4(고민서) 순으로 완료 현황을 공유하였으며, 전원 머지 준비 완료 상태임을 확인하였다.

### 2. Git 머지 전략 논의

각 담당자의 작업 브랜치를 `main` 브랜치에 통합하는 방식으로 머지 전략을 확정하였다. 머지 전 PR을 생성하여 팀원 간 코드 리뷰를 거치기로 하였으며, 충돌 발생 시 해당 담당자가 직접 해결 후 팀에 공유하기로 하였다. 머지 완료 기한은 **2026년 6월 3일(수요일)**로 확정하였다.

### 3. 최종 시연 일정 논의

머지 완료 당일인 **2026년 6월 3일(수요일)**에 4개 Task 전체 통합 기능을 대상으로 최종 시연을 진행하기로 확정하였다. 시연은 통합된 `main` 브랜치 기준으로 진행하며, 시연 중 발견된 버그는 톡방에 올려 대응하기로 하였다.
