## IV. 회의 내용

### 1. 신규 기능 추가

고객센터 또는 FAQ 기능을 추가하기로 하였다. 웹에는 추가하되, 앱에서는 어느 화면에 배치할지 추가로 고민하기로 하였다. 또한 서비스 소개 후 앱 다운로드 주소로 안내하거나 웹에서 바로 사용할 수 있도록 대시보드로 연결하는 index 페이지를 추가하기로 하였다.

AI 챗봇 추가에 대해서도 논의하였다. 현재 동시에 여러 답변을 요청하면 멈추는 현상이 있고, 무료 버전의 경우 사용량이 금방 소진되는 문제가 있어 이에 대한 학습과 대응이 필요하다는 의견이 나왔다.

### 2. 앱 메일 파싱 성능 개선

앱에서 메일 파싱 시간이 지연되는 문제를 **최우선(1순위) 과제**로 정하였다. 페이지 하이딩 및 코드 수정을 통해 처리 시간을 단축하기로 하였다.

### 3. UI 색상 및 버튼 배치 개선

구글 원의 '해지하기' 버튼 색상이 다른 서비스의 해지하기 버튼 색과 달라 사용자 혼란을 줄 수 있어, 색상을 변경하고 '구글 원 열기' 버튼과 색상을 교환하기로 하였다. 모바일 앱에서는 '구글 원 열기' 버튼이 위에 있어 '해지하기'와 혼동되므로, 정기 결제 페이지 이동 버튼을 위로 올리기로 하였다.

굿노트 역시 색상 변경이 필요하며, 다른 서비스에도 색상 변경이 필요한지 함께 검토하기로 하였다. 이 외에 웹 구독 가성비 리포트의 '줄일 수 있는 지출' 부분 이모지 정리, 라이트/다크 모드 전환 시 발생하는 배치 문제도 수정하기로 하였다.

### 4. 불필요 기능 정리 및 설정 페이지 신설

웹과 앱의 연동 계정 관리 기능, 결제 알림 메일 기능을 삭제하기로 하였다. 리포트 탭의 '절약 기록 보기'는 앱과 내용을 일치시키기 위해 제거하며, 기존 결제 알림 자리에는 설정 페이지를 새로 만들기로 하였다. 체크인 기능은 판단 기준을 별도로 설정할 필요가 있다는 의견이 나왔다.

### 5. 간편 로그인 및 계정 통합

웹 사이트 가입 시 입력한 이메일과 간편 로그인 계정이 겹쳐 로그인이 불가능한 문제가 확인되어, 계정 통합 방식으로 해결하기로 하였다. 통합 시 아이디 자체를 이메일로 설정할지는 추가 검토가 필요하며, 통합으로 새 아이디를 생성하는 경우 이전 데이터를 통합할지 초기화할지를 사용자에게 질의하기로 하였다. 또한 카카오 간편 로그인은 서비스 설정 오류를 수정하기로 하였다.

### 6. 앱 → 웹 전환 동작 문제

앱에서 간편 로그인 시 웹으로 이동하고, 이후 동작까지 웹에서 진행되는 문제가 있다. 가능하면 앱 to 앱으로 처리되도록 수정하고, 필요하다면 로딩 페이지를 만들기로 하였다. 간편 로그인 외의 다른 기능도 앱에서 웹으로 넘어가 동작하는지 검토하고 수정하기로 하였다.

### 7. 작업 방식 및 역할 분담

위 수정 및 개선 사항은 각자 최신 코드를 반영한 뒤 작업하고, PR(Pull Request)을 통해 처리하기로 하였다. 조원 이혁제는 앱 출시 홍보 담당을 맡았다.
